## 克隆和校验

建议在Linux或WSL中克隆，保留符号链接和执行权限：

```bash
git -c core.autocrlf=false clone https://github.com/feeasolfnj/XSAI_AIRAN.git
cd XSAI_AIRAN
python3 scripts/verify-publication-snapshot.py
```

成功输出表示源码与这次K3快照一致，不代表依赖已经安装、编译或链路测试已经完成。

## 准备一个新的 OAI 工作目录

```bash
# 目标必须是尚不存在的新目录；不修改已有部署
bash scripts/prepare-oai-worktree.sh "$HOME/xsai-oai"
```

脚本复制vendor快照，并把OAI的plugins链接到本仓库。然后按 [项目与环境指南](K3_PROJECT_GUIDE.md) 配置本机工具链和依赖。不要直接复制原板子的CMake缓存或二进制。

已有合适的本地OAI构建后，可以用独立的 [xsai-module-benchmark](https://github.com/feeasolfnj/xsai-module-benchmark) 测量模块：

```bash
# 在benchmark仓库中执行，按本地实际目录填写
python3 bench.py build --xsai "$HOME/xsai-oai" --only DL
python3 bench.py run DL --threads 1 --cpus 0
```

benchmark本身是另一个仓库，不包含在此快照内。
